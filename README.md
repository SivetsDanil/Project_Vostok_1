<h1>Восток-1: повторяем полёт Гагарина в KSP</h1>

Проект по курсу ВАРКТ. Повторяем полёт Ю. А. Гагарина 12 апреля 1961 года: ракета «Восток» 8К72К,
один виток вокруг Земли, баллистический спуск. Полёт выполняется в стоковой Kerbal Space Program 1.12.5
(планета Кербин) с автопилотом на Python (kRPC), результаты сравниваются с мат. моделью и с реальным полётом.

Основа — наш прошлый проект [Project_Voyager_1](../Project_Voyager_1).

## Что повторяем

| Характеристика | «Восток-1» (Земля) | Наш полёт (Кербин) |
|---|---|---|
| Схема ракеты | пакет: 4 боковых блока + блок А, затем блок Е | так же, все 5 двигателей запускаются на старте |
| Отделение боковых блоков | T+119 с | T+118 с (по выгоранию) |
| Сброс обтекателя | T+156 с | T+156 с |
| Отделение блока А | T+300 с | T+300 с |
| Выключение блока Е | T+657 с | ≈T+657 с (подобрано моделью) |
| Орбита | 181 x 327 км, наклонение 64,95° | 181 x 327 км, 65° (курс старта ≈21°) |
| Торможение | на 0,76 витка, ТДУ ≈42 с | на 0,76 витка, «Spark» ≈42 с |
| Спуск | баллистический, катапультирование на 7 км, парашют на 2,5 км | так же (выход в EVA вручную) |

**Что не повторить на Кербине** (он в 10,6 раза меньше Земли): период орбиты ≈44 мин вместо 89,
весь полёт ≈1 ч вместо 108 мин, масса ракеты ≈34 т вместо 287 т. Скорость на орбите Кербина всего ≈2,2 км/с,
поэтому если оставить тягу 8К72К, ракета разгонится до земных 8 км/с: блок А и блок Е у нас работают
столько же, сколько настоящие, но с малой тягой. Стартовая тяговооружённость 1,27 вместо 1,39, перегрузка на выведении ≈3,4 g вместо ~5 g, а на спуске ≈2,6 g вместо 8–10 g (вход в атмосферу на 2,2 км/с вместо 7,8 км/с).

## Структура

```
README.md, CRAFT_SPEC.md        — описание и инструкция по сборке ракеты в VAB
coding/
├── mission_params.py           — все характеристики полёта и ракеты в одном месте
├── guidance.py                 — программа выведения (общая для автопилота и модели)
├── requirements.txt
├── ksp/
│   ├── autopilot_vostok.py     — автопилот: старт → орбита → ТДУ → спуск, итоги и графики
│   ├── telemetry.py            — запись телеметрии в CSV в фоне
│   └── time_warp.py            — ускорение времени (из Voyager без изменений)
└── mat_model/
    ├── objects.py              — блоки ракеты
    ├── calc.py                 — модель полёта: выведение, виток, торможение, спуск
    ├── graphs.py               — графики «модель vs KSP» + реальная циклограмма
    ├── tune_vehicle.py         — подбор тяги и тангажа под циклограмму
    └── data/                   — сюда автопилот пишет ksp_flight.csv и ksp_events.csv
```

## Как запустить

1. Установить зависимости: `pip install -r coding/requirements.txt`.
2. Мат. модель работает без игры: `python coding/mat_model/graphs.py`.
3. В KSP 1.12.5 установить мод kRPC (через CKAN), собрать ракету по [CRAFT_SPEC.md](CRAFT_SPEC.md),
   поставить на стартовый стол и запустить сервер kRPC.
4. `python coding/ksp/autopilot_vostok.py` — полёт целиком. На высоте 7 км автопилот попросит
   выйти кербонавтом в EVA и раскрыть парашют (kRPC не умеет выходить из корабля).
5. Снова `python coding/mat_model/graphs.py` — теперь на графиках будут данные из KSP,
   а атмосфера в модели возьмётся из телеметрии.

После сборки ракеты впишите фактические массы из VAB в `mission_params.py` и запустите
`python coding/mat_model/tune_vehicle.py` — он подберёт ограничители тяги и тангаж заново.
