#  Введение в авиационную и ракетно-космическую технику

### Команда: ***Космос не предел***
### Миссия: ***Восток-1***

# Описание
Повторяем полёт Ю. А. Гагарина 12 апреля 1961 года: ракета-носитель «Восток» 8К72К, один виток вокруг планеты, баллистический спуск. Полёт выполняется в Kerbal Space Program 1.12.5 без модов (кроме kRPC) на планете Кербин.

+ Код из файла `coding/ksp/autopilot_vostok.py` через модуль krpc проводит весь полёт: старт пакета из 5 блоков, выход на орбиту 181 x 327 км с наклонением 65°, один виток, торможение, разделение корабля и спуск. В конце печатает сравнение с реальным полётом и строит графики *высоты*, *скорости* и *перегрузки* от времени.
+ Код из файла `coding/ksp/telemetry.py` во время полёта записывает высоту, скорость, перегрузку, давление, плотность воздуха и координаты в `coding/mat_model/data/ksp_flight.csv`, а моменты событий — в `ksp_events.csv`.
+ Код из файла `coding/ksp/time_warp.py` ускоряет время до нужного момента (виток, торможение, вход в атмосферу).
+ Код из файлов `coding/mat_model/calc.py` и `coding/mat_model/objects.py` — мат. модель полёта: тяга с учётом давления, сопротивление воздуха, разделение ступеней, расчёт орбиты, торможение и спуск на парашюте.
+ Код из файла `coding/mat_model/graphs.py` строит графики мат. модели и данных из KSP и отмечает на них моменты реального полёта. Работает и без данных KSP.
+ Код из файла `coding/mat_model/tune_vehicle.py` подбирает тягу ступеней и тангаж так, чтобы ступени отделялись в те же секунды, что у настоящего «Востока».
+ В файле `coding/mission_params.py` собраны все характеристики реального полёта и ракеты для KSP, `coding/guidance.py` — программа выведения, общая для автопилота и модели.

### Что повторяем

| | «Восток-1» | Наш полёт |
|---|---|---|
| Отделение боковых блоков | T+119 с | T+118 с |
| Сброс обтекателя | T+156 с | T+156 с |
| Отделение блока А | T+300 с | T+300 с |
| Выключение блока Е | T+657 с | T+655 с |
| Орбита | 181 x 327 км, 64,95° | 181 x 327 км, 65° |
| Торможение (ТДУ) | 42 с, ~150 м/с | 41 с, 146 м/с |
| Катапультирование / парашют | 7 км / 2,5 км | 7 км / 2,5 км |

> Кербин в 10,6 раза меньше Земли, поэтому не совпадают: период орбиты (44 мин вместо 89), длительность полёта (66 мин вместо 108), масса ракеты (36 т вместо 287 т), тяговооружённость на старте (1,21 вместо 1,39) и перегрузка на спуске (2,6 g вместо 8–10 g).

### В папке [KSP](KSP) лежит `.craft` файл ракеты «Восток» — собирать её самим не нужно. Скопируйте `Vostok-1.craft` в `saves/<ваше сохранение>/Ships/VAB` и выберите ракету в VAB.
> Ракета собрана из стоковых деталей, ограничители тяги и топливо уже выставлены. Из модов нужен только kRPC.

Порядок ступеней (по нажатию пробела), автопилот проходит их сам:
1. Зажигание: 4 «Swivel» боковых блоков + «Spark» блока А
2. Отвод опор
3. Отделение боковых блоков (4 радиальных разделителя TT-70)
4. Сброс обтекателя
5. Отделение блока А, запуск «Terrier» блока Е
6. Отделение корабля, взвод ТДУ («Spark» приборного отсека)
7. Отделение приборного отсека (теплозащитный экран)
8. Парашют спускаемого аппарата

#

### Как запустить
+ `pip install -r coding/requirements.txt`
+ В KSP поставить ракету на стартовый стол, включить сервер kRPC и запустить `python coding/ksp/autopilot_vostok.py`. На высоте 7 км выйдите кербонавтом в EVA и раскройте его парашют — это «катапультирование» (kRPC не умеет выходить из корабля).
+ После полёта `python coding/mat_model/graphs.py` построит графики «мат. модель vs KSP».
